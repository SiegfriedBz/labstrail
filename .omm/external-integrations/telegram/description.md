Telegram Bot API (sendMessage, parse_mode HTML): every message for the maintainer, in one chat for every environment, each headed by its kind and environment (ADR 0038). createNotify (workflows/src/alerts/notify.ts) sends it with TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID, only logs without them (locally; production refuses to start without them), and never throws. Activity: a paper published, a rating scored or cancelled, or delayed (a rating run that gave up while its request stays pending: why, when it would be cancelled), with the paper's title and a short link. Alerts, for what the maintainer must fix: a failed or cancelled run but a delayed rating, an oracle without funds or at its fee cap, an orphan R-KA or one an oracle move may leave unrecorded, the DKG node down or its graph not finalized, low wallet balances and old pending requests.
