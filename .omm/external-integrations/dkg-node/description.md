The OriginTrail DKG V10 node on the node server (DKG_URL, https://verisci-dkg.duckdns.org): stores and mints Knowledge Assets and answers SPARQL over the verisci-staging and verisci-main-prod context graphs (production's since 2026-10-19; the retired verisci-prod stays subscribed, unused). Caddy lets in each environment's own credential, sent as DKG_TOKEN, and calls the node with its admin token, which no environment holds (ADR 0039); its health check, /api/status, is open, and the hourly health check reads it with no credential (ADR 0038). Every credential reaches both graphs, so the dkg package refuses the production graph outside production (ADR 0005).
