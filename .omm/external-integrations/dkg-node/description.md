The OriginTrail DKG V10 node on the node server (DKG_URL, https://verisci-dkg.duckdns.org): stores and mints Knowledge Assets and answers SPARQL over the verisci-staging and verisci-prod context graphs. Caddy lets in each environment's own credential, sent as DKG_TOKEN, and calls the node with its admin token, which stays on the server (ADR 0039). Every credential reaches both graphs, so the dkg package refuses the production graph outside production (ADR 0005).
