Reown AppKit with wagmi (REOWN_PROJECT_ID, read from the server's settings at request time): connects the visitor's wallet on Base Sepolia, and locally on Anvil too, for ratings (ADRs 0034, 0036); asks it to sign the submission, and sends a rating request (requestPhase1) from it. It loads only when used: components/wallet/wallet-runtime.ts, the only module importing AppKit and wagmi, is reached through import() on a wallet action (the download starts when the pointer or focus reaches a wallet button) or once the page is idle when the browser keeps AppKit's connected status, so no page calls Reown's or Coinbase's servers before then. AppKit's vanilla set-up and wagmi's actions share the adapter's config, with no React provider. The wallet window names VeriSci with lib/site.ts's SITE. Without a project id the pages still render and say the wallet is not set up.
