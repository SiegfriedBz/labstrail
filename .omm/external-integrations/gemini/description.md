The Gemini API's generateContent (GEMINI_API_KEY in the x-goog-api-key header), one shared call in workflows/src/gemini/gemini.ts with a JSON schema at temperature 0: gemini-3.5-flash-lite checks a paper's field, in the publish run for each new paper and in the rating run before scoring (ADR 0037), and gemini-3.8-flash scores each paper in one request in the rating run (ADR 0018), both on the free tier, each model with its own daily quota. Failures map to rate-limited (429), refused (other 4xx), unreachable (5xx, network, timeout) and invalid-output.
