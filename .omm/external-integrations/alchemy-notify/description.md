Alchemy Notify: one Custom Webhook (GraphQL) per environment on Base Sepolia, created with skip_empty_messages, taking every event of its current RatingController and delivering them to apps/web's POST /api/webhooks/alchemy, signed with X-Alchemy-Signature, a hex HMAC-SHA256 of the raw body under the webhook's signing key (ALCHEMY_WEBHOOK_SIGNING_KEY). Delivered at least once (ADR 0017): the intake (workflows/src/site/webhook.ts) checks the signature before parsing, keeps the Phase1Requested logs and sends one verisci/rating.requested event per request with the id rating:<request id>, and answers 503 when Inngest refuses, so Alchemy Notify delivers again. After a reorg it delivers the new block; the run's read of the request on chain stops a dropped one. The reconciler finds what it misses (ADR 0020).
