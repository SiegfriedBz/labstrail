On chain: anyone calls RatingController.requestPhase1(targetUal), paying only gas on testnet (ADR 0015), from a paper's page with their wallet; the contract records the request as pending under a new request id and emits Phase1Requested. The oracle later fulfils it with the score and the R-KA's UAL, or cancels it. Locally, the paper's page has the server announce the request from its receipt (or the rate-paper dev script requests one and sends the event itself); on staging, an Alchemy Notify webhook will (ADR 0017).
