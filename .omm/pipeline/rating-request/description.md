On chain: anyone calls RatingController.requestPhase1(targetUal), paying only gas on testnet (ADR 0015); the contract records the request as pending under a new request id and emits Phase1Requested. The oracle later fulfils it with the score and the R-KA's UAL, or cancels it. Today the rate-paper dev script requests one on Anvil and sends the event itself; on staging, an Alchemy webhook will (ADR 0017).
