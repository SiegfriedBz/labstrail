Step read-paper-<n>: fetches the PDF through the gateway and extracts its text with unpdf (workflows/src/pdf/), prepared and cut to 150,000 characters. A scan with no text or a file over 15 MB cancels invalid-target; a file that does not read as a PDF is read again and cancels after 4 bad reads, at least 22 minutes apart in all; a run's first read the gateway does not give is tried once more 15 s later (read-paper-<n>-wait, then read-paper-<n>-again), then retried with the attempts (paper-unreachable, naming the cause).
