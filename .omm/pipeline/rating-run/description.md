The rate-paper function (workflows/src/rating/rate-paper.ts), a singleton per request id with 300 minutes: it checks the request, checks the target is a paper verisci published, then reads the R-KA's state and does only what is left. Each part of the score (the PDF link with the title and abstract, the text, the field check, Gemini's answer) is asked for once per run and kept across attempts, which wait 2, 5, 15, 30, then 60 minutes. Once the oracle settles the request, a notify step sends one activity message (ADR 0038). Started by the webhook's intake, the reconciler, or locally the page.
