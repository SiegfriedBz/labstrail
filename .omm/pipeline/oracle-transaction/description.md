The oracle-transaction function (workflows/src/rating/oracle.ts), invoked by a rating run: it reads the request (already fulfilled with the same R-KA or cancelled counts as done, ADR 0007), sends fulfilPhase1 or cancelRequest from the oracle's key, bumping the fee up to a cap when a transaction is stuck, and checks the receipt in later steps. Only one runs at a time, so oracle transactions never race for a nonce (ADR 0019). An oracle without funds, and a transaction at the fee cap, alert the maintainer once a run (ADR 0038).
