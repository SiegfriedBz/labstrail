Step ids carry the attempt number (parse-paper-1, score-paper-v4-2) and change when a step's result changes shape, so a run already going never reads an old result as a new one. Failures end with publish-failed:<reason> or rating-failed:<reason>; the paper's page reads the publish reason (publishFailureReason). The rating pages show a rating's stage and, once cancelled, why, but not why a run failed: that shows in Inngest's run output.
