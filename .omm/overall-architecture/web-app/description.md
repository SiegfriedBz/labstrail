The Next.js 16 App Router site (apps/web/): the home page, the publish page, the papers list with each paper's score, each paper's page with its Ratings section, and each rating's page; three server actions (requestUpload, submitPaper, and announceLocalRating locally), the route that serves the Inngest functions, and the two routes the paper and rating pages poll. Server reads and actions return typed results (ADR 0021). It imports all five packages, compiled through transpilePackages.
