The helpers at apps/web/lib's root: web-env.ts (the app's own settings, validated with defineEnv), server.ts (the upload limits, built once from those settings), site.ts (SITE, the name and the description that names VeriSci's field, read by the layout's metadata, the footer and the wallet window), theme.ts (the script that sets the theme before the first paint), shorten.ts (short addresses and CIDs), utils.ts (shadcn's cn) and empty-module.ts (an empty module next.config.ts puts in place of one the bundle must not load, docs/domain.md → Next.js).
