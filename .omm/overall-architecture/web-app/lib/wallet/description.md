apps/web/lib/wallet/: the wallet's loading, kept out of the components so unit tests cover it without AppKit. session.ts (hasStoredWalletSession, from AppKit's @appkit/connection_status, and WALLET_SESSION_SCRIPT, which marks <html data-wallet="restoring"> before the first paint so Connect never flashes before a returning visitor's address), loader.ts (createWalletLoader: builds the runtime once per page load, again only after a failed build) and store.ts (createWalletStore: idle, loading, restoring, connected, disconnected or failed, following the runtime's account once loaded; load for a wallet action, preload when the pointer or focus reaches a wallet button, restore once the page is idle).
