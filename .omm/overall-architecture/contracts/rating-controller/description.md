src/RatingController.sol (with src/interfaces/IRatingController.sol): anyone requests a phase-1 rating of a target UAL (requestPhase1), which emits Phase1Requested with an on-chain request id; the id hashes the chain id, the contract's address and deploy time (DEPLOYED_AT), a nonce, the requester and the target, so no two requests share one, even on a contract redeployed at the same address on a restarted Anvil (ADR 0016). Only the oracle fulfils a request with a score from 0 to 100 and the R-KA's UAL (fulfilPhase1) or cancels it (Expired, InvalidTarget). Each requester may hold a capped number of pending requests (ADR 0015); the contract lists each target's request ids, oldest first (ADR 0022). The owner (offline, never the oracle, ADR 0030) pauses, sets the oracle and the cap, and transfers ownership in two steps (ADR 0023); a replaced contract is paused once its successor is live, and settles what is still pending on it. Tested with Foundry unit and invariant tests.
