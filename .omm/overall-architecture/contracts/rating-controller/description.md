src/RatingController.sol (with src/interfaces/IRatingController.sol): anyone requests a phase-1 rating of a target UAL (requestPhase1), which emits Phase1Requested with an on-chain request id; only the oracle fulfils it with a score from 0 to 100 and the R-KA's UAL (fulfilPhase1) or cancels it (Expired, InvalidTarget). Each requester may hold a capped number of pending requests (ADR 0015); the contract lists each target's request ids, oldest first (ADR 0022). The owner (offline, never the oracle, ADR 0030) pauses, sets the oracle and the cap, and transfers ownership in two steps (ADR 0023). Tested with Foundry unit and invariant tests.
