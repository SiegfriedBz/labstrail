The typed client of the DKG node's HTTP API (packages/dkg/src/client.ts): read an asset's state (missing, draft, stored, minted), store its triples, start its mint, run a SPARQL query, and check that the node serves the context graph. It returns typed results for every expected failure and never retries itself; its settings (node URL, token, graph) are validated in src/dkg-env.ts, with a guard that refuses the production graph outside production.
