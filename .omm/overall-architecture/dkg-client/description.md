The typed client of the DKG node's HTTP API (packages/dkg/src/client.ts): read an asset's state (missing, draft, stored, minted), store its triples, start its mint, run a SPARQL query, check that the node serves the context graph, and read the node's open health check (/api/status, sent with no credential) for the health check's alert. It returns typed results for every expected failure and never retries itself; its settings (node URL, token, graph) are validated in src/dkg-env.ts, with a guard that refuses the production graph outside production.
