Dependency direction (root CLAUDE.md): env and core depend on nothing; dkg and contracts on core and env; workflows on core, env, dkg and contracts; web on all five; the RPC proxy on nothing. core does no IO (Biome enforces it), so every rule lives there and the adapters (dkg, contracts, workflows) do the IO. Inngest functions live in workflows and the web app only serves them (ADR 0003). The chain and the DKG hold the truth; the app's only state is its rate limits in Upstash (ADR 0035).
