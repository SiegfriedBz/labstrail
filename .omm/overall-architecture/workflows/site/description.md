src/site/: the services the web app's server code calls. upload.ts (getUploadService): a signed Pinata upload URL, a submission checked and sent as verisci/paper.submitted, a paper's status from the DKG node and the publish run (runs.ts reads the run's state from Inngest's API), and the published papers list read from the graph with each signature checked (papers.ts). ratings.ts (getRatingService): a paper's rating requests on the environment's contracts, current and past, or locally the Anvil one; one rating with its stage from its R-KA on the node or its R-KA's record; each listed paper's summary (summariseRatings, the rule the list and the paper page share); and locally the announce of a request from its receipt. Its chain calls are tried once, 5 s each.
