The workflows' root: index.ts (the main entry the web app imports, which validates no settings), inngest.ts (the Inngest client, in dev mode locally), env.ts, workflows-env.ts and rating-env.ts (the settings each function validates on its first run, and what a deployed server checks at start), and functions.ts (servedFunctions: the publish function everywhere, the rating and oracle functions only where the oracle key is set, each with its real adapters).
