The workflows' root: index.ts (the main entry the web app imports, which validates no settings), inngest.ts (the Inngest client, in dev mode locally), env.ts, workflows-env.ts (the settings every function and a deployed server's start check read, GEMINI_API_KEY, the optional Telegram bot and chat and the optional Alchemy Notify signing key among them; webhookSchema adds the Anvil contract the webhook's intake reads locally) and rating-env.ts (the oracle key, the publisher wallets the health check watches, and the local chain, for the rating functions; the site's ratings service and the fund-local script read the local chain too), and functions.ts (servedFunctions: the publish function and the failure alerts everywhere, the rating, oracle, reconciler and health functions only where the oracle key is set, each with its real adapters; the notifier is built from the Telegram settings alone, so an alert still goes out when another setting is bad).
