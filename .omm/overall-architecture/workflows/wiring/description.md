The workflows' root: index.ts (the main entry the web app imports, which validates no settings), inngest.ts (the Inngest client, in dev mode locally), env.ts, workflows-env.ts (the settings every function and a deployed server's start check read, GEMINI_API_KEY among them) and rating-env.ts (the oracle key and the local chain, for the rating functions), and functions.ts (servedFunctions: the publish function everywhere, the rating and oracle functions only where the oracle key is set, each with its real adapters).
