src/pdf/: what both runs use to read a paper. fetch-pdf.ts fetches a pinned file through the Pinata gateway by CID, within a size limit (15 MB) and a timeout, and checks it starts with %PDF-. paper-text.ts extracts each page's text with unpdf and prepares it with core's preparePaperText for the scorer; it answers no-text for a scan, too-large, unreadable or unreachable, and never throws.
