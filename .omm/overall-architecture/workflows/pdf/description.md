src/pdf/: what both runs use to read a paper. fetch-pdf.ts fetches a pinned file through the Pinata gateway by CID, within a size limit (15 MB) and a timeout, and checks it starts with %PDF-. paper-text.ts extracts each page's text with unpdf and prepares it with core's preparePaperText: the whole text for the scorer, and the first 6,000 characters for the publish run's field check (paperTextOf), whose unreadable and no-text answers the publish run refuses too; paperTextOf also returns the title the PDF stores (its info dictionary's Title, else its XMP dc:title) as storedTitle, which only the publish run reads. It answers no-text for a scan, too-large, unreadable or unreachable, and never throws.
