Dev-only scripts (packages/workflows/scripts/), run with plain Node: publish-pdf (pins a PDF, signs it and sends the publish event to the local dev server), rate-paper (requests a rating on the local Anvil contract and sends the rating event, ADR 0036; with --no-event it only prints the transaction), post-webhook (builds a signed Alchemy Notify delivery from a request's Anvil receipt and posts it to the local webhook route), fund-local (gives a wallet 1 ETH on Anvil, so it can request a rating from the paper page), and score-papers (scores the 14 reference papers in reference-papers.json with Gemini and compares each with its expected study types, answers and score range; --repeat scores each paper several times and prints how far the runs agree, from stability.ts: study types, scores and spread, answer flips and quote flips; --pdf also scores a PDF on disk with no expectations; --thinking asks for a thinking level; score-args.ts reads the arguments and refuses a run over the free tier's 20 scorer requests a day; with --field, runs only the publish run's field check on them). None runs in CI.
