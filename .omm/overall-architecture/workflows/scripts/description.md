Dev-only scripts (packages/workflows/scripts/), run with plain Node: publish-pdf (pins a PDF, signs it and sends the publish event to the local dev server), rate-paper (requests a rating on the local Anvil contract and sends the rating event, ADR 0036), and score-papers (scores the 14 reference papers in reference-papers.json with Gemini and compares each with its expected study type, answers and score range; with --field, runs only the publish run's field check on them). None runs in CI.
