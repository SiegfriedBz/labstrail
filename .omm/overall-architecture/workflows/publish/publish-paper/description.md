publish-paper.ts: runPublish and the publish-paper Inngest function, a singleton per CID with a 45-minute budget. It verifies the event, then reads the Target KA's state and does only what is left (ADR 0007): read the paper, store its triples, start the mint and poll it (ADR 0008), retrying with step.sleep (ADR 0009). A KA already stored or minted keeps its first submitter. Refusals (not a PDF, too large, unparseable, no title) end the run; failures carry publish-failed:<reason> for the paper's page.
