src/publish/: the publish-paper function (a singleton per CID) that turns a submitted PDF into a Target KA (ADR 0010), with what it uses: the submission check (signature, deadline, graph) and GROBID's header parse. Beside it, what the site service uses before a run starts: submit-paper (the server-side check that sends the event) and the Pinata adapter. The pipeline perspective shows the run's steps.
