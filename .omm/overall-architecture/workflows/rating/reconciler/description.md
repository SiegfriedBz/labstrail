reconciler.ts and pending.ts: the reconcile-ratings cron (ADR 0020), every 30 minutes and a singleton. It reads each of the environment's contracts in a step of its own, one after the other: one page of 100 pending ids a tick, in turns, and each request 10 at a time (readPending, which the health check shares), and sends the rating event again for each one pending over 4 hours, with an id per 4-hour window, so Inngest starts at most one run per request per window. It never writes: the rating run decides what is left. A contract that does not answer is logged reconcile-unreachable, requests that do not answer reconcile-unreadable.
