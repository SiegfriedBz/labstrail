oracle.ts and oracle-chain.ts: the oracle-transaction function, invoked by a rating run, sends fulfilPhase1 or cancel from the oracle's key, one transaction at a time (ADR 0019), reading the request first so an already-settled one counts as done (ADR 0007), bumping fees up to a cap, and checking the receipt in later steps. It alerts once a run when the oracle cannot pay (alert-no-funds) and when a transaction reaches the fee cap (alert-fee-cap), ADR 0038. Only develop and main hold the oracle keys; locally, Anvil's second account (ADR 0036).
