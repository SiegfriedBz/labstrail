The DKG node server's configuration (infra/node-server/, copied to the server by hand, docs/node-host.md): Caddy, its only public entry, serves verisci-dkg.duckdns.org and verisci-grobid.duckdns.org over HTTPS, lets in each environment's credential (local, staging, production) and forwards to the DKG daemon with its admin token, or to GROBID without a credential; the health check, /api/status, is open and reaches the daemon with no token (ADR 0039). Caddy's systemd drop-in gives it the secrets, starts it with its config alone (Ubuntu's unit would log every variable) and refuses an empty secret; systemd starts the daemon after the RPC proxy.
