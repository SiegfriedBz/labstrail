The DKG node server's configuration (infra/node-server/, not a workspace): Caddy, its only public entry, serves verisci-dkg.duckdns.org and verisci-grobid.duckdns.org over HTTPS, lets in each environment's credential (local, staging, production) and forwards to the DKG daemon with its admin token, or to GROBID without a credential (ADR 0039); systemd starts the daemon after the RPC proxy. The files are copied to the server by hand (docs/node-host.md).
