A small JSON-RPC proxy beside the DKG daemon on 127.0.0.1:8545 (infra/rpc-proxy/, plain Node, standard library only, imported by nothing). The daemon takes a single chain.rpcUrl, and this proxy is that URL: it spreads the daemon's Base Sepolia reads over free public endpoints and keeps Alchemy, the fallback, within a daily budget (src/budget.ts). It reads its own settings (ADR 0004).
