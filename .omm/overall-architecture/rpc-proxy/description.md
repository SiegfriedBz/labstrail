A small JSON-RPC proxy beside the DKG daemon on 127.0.0.1:8545 on the node server, run by systemd (infra/rpc-proxy/rpc-proxy.service; plain Node, standard library only, imported by nothing). The daemon takes a single chain.rpcUrl, and this proxy is that URL: it spreads the daemon's Base Sepolia reads over free public endpoints and keeps Alchemy RPC, the fallback, within a daily budget (src/budget.ts). It reads its own settings (ADR 0004).
