An OriginTrail DKG V10 node on the node server, a free Oracle Cloud VM (ADR 0006, docs/node-host.md), with GROBID beside it: it stores each asset's triples, mints it on Base Sepolia as an ERC-721 token with the merkle root of its statements, and answers SPARQL over the staging and production context graphs. Its publisher wallets pay the mint fees. Every environment, developers' computers included, reaches it through Caddy (infra/node-server/).
