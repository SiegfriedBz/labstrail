POST /api/webhooks/alchemy (app/api/webhooks/alchemy/route.ts): the Alchemy Notify webhook's delivery, its raw body and X-Alchemy-Signature handed to the workflows' intake (getWebhookIntake), whose status it answers with an empty body: 200, 401 for a missing or wrong signature, 400 for a body that is not a delivery, 503 when Inngest refuses the events so Alchemy Notify delivers again, 404 where no signing key is set (feature previews) (ADR 0017).
